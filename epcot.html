EPCOT Brand Recreation

Created with:

Adobe Photoshop, Fresco, Illustrator

Originally started as an exploration of Illustrator program tools, this project faithfully reproduces the updated park graphics for the 2019 EPCOT transformation.

As more information about the park's transformation was released, I became fascinated by the new graphic design system, which recalled the futuristic vision from its early years.

After countless hours scouring the internet, compiling images and other ephemera, and modifying and sketching elements in Photoshop and Fresco, I meticulously redrew the graphics in Illustrator to create a full system of wordmarks, pavilion icons, letterforms, and wayfinding symbols.

This project will continue to expand as more reference images become available, with the eventual goal of using these elements as the basis for a larger UI project themed to the park.
